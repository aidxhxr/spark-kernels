# Results (RTX 5090)

This file is generated by `python3 scripts/make_results_table.py` from `results/*.json` after
`make bench` has been run. It has not been generated yet: nothing has been run on either
machine.

Run:

```bash
make build && make bench && make results
```

Notes on what the generated tables will contain:

- Ceilings are the RTX 5090's: 1,792 GB/s (GDDR7 spec) and 104.8 TFLOPS fp32. Provenance in
  [RTX5090.md](RTX5090.md).
- "% of peak" on the `hgemm` rows prints "—" until a measured bf16 tensor-core peak is supplied
  with `--bf16-peak=<TFLOPS>` (same flag on `scripts/roofline.py`). "% of cuBLAS" does not need it.
- Each bench row records the `device` it ran on and `min_ms` next to the median.
- The scripts generate this file for one machine at a time, from the `device` field in the
  rows, and refuse a `results/` directory that mixes machines. GB10 (DGX Spark) numbers
  (`make build ARCH=121`; ceilings in [GB10.md](GB10.md)) will be generated separately once
  that machine has been benchmarked.
